日期：2026-11-26。状态：研究综合初步完成；转入受控科研协同。不是训练或发布授权。

1. `research/01-synthesis.md`：十四轮结论与竞争路线。
2. `knowledge/claims.tsv`、`knowledge/hypotheses.tsv`：101 条候选知识、42 条原编号假设（压缩转述，未独立复现）。
3. `research/02-literature.md`：核心论文与资产入口；不是完整文献计量档案。
4. `governance/01-protocol.md`：证据、评价、阶段门禁及 MP01–30。
5. `agent/START-HERE.md`：Coding Agent 可直接使用的协同任务书。
6. `evidence/limitations.md`：阻塞、证据边界和勘误。

本包是可执行交接用的综合档案，不是十四轮聊天逐字备份。来源链接是研究入口，历史会话中的引用标记不具备跨文件持久性，因此不伪造引用。包内未包含第三方论文全文、源代码、原始实验数据或运行结果。所有外部来源在采用前应固定版本并核验。
