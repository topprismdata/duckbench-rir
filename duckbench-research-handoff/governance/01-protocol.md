# 证据与科研门禁

## 证据契约
来源维度：THEORY / SIM-EXP / REAL-EXP / OFFICIAL / ENGINEERING-OBS / SYNTHESIS / HYPOTHESIS。核验维度：IDENTIFIED / SOURCE-CHECKED / AUDITED / RECOMPUTED / REPLICATED；CHALLENGED独立反证标志（不覆盖核验状态）。每项声明必须绑定精确来源、版本/日期、页节/图表、条件、限制、反证、责任人与裁决。原始数据缺失标BLOCKED，不用自报数据冒充复算。所有新增证据追加式，原始文件哈希固定。

## 实验协议（候选，未冻结）
单变量对照优先；记录交互效应而非强行单因归因。固定任务、物理模型、观测权限、动作物理边界、独立评测集；公平调参预算。独立训练种子与评价种子分开；初筛至少5个训练种子作为起点，不宣称统计功效充分。确认性实验预注册效应量、置信区间、样本量及失败处理；测试集隔离、全样本保留。报告均值、中位数、IQM（跨任务时适用）、置信区间、成功率、下尾CVaR、达到阈值时间/样本、失败率、固定预算性能。竞赛最佳成绩单列。环境步、物理步、训练更新、回放抽取、墙钟、编译、内存、调参及人工先验成本分开。模型预测、关键接触事件、梯度有效性与控制效果分别验收。

## 物理门禁 PG01–09
PG01来源/质量/惯量；PG02关节及几何可达；PG03力矩速度包络；PG04功率能量负载；PG05接触/滑移/穿透；PG06时延饱和回差；PG07步长/求解敏感性；PG08跨模型测试；PG09实体验证（未授权）。每项必须定义测量、阈值、范围与不能证明什么；部分PASS不是整体物理有效。失败归因优先检查接口→数值→物理→执行→观测→学习，允许多因和UNKNOWN。
