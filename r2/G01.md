容差：`torque_Nm = 1e-12`、`angle_rad = 1e-12`、`velocity_rad_s = 1e-12`、`friction_Nm = 1e-12`（同公式、float64 下应为 0）。

|---|---|---|---|---|
| 电机力矩（kit `motor_torque` vs BAM `VoltageControlledActuator`） | 225 | 0.0 | N·m | PASS |
| 其中 dq=0 的角度行 | 45 | 0.0 | rad（经 kt/R 到 N·m） | PASS |
| 其中 dq≠0 的速度行 | 180 | 0.0 | rad/s（经反电动势到 N·m） | PASS |
| 摩擦预算（kit `friction_budget` vs mjlab GPU 形式转录） | 125 | 0.0 | N·m | PASS |

## 4. 参数溯源

manifest 的 14 个 BAM 参数与 `bam/params/xl330/m6.json` 逐项相等（脚本输出 `params` 表），且在 `62bd8ce` 与 `57d13ead` 两个 commit 完全相同（该 json 的 sha256 一致：`61c69936…`）。`kp_fw=200`、`error_gain=0.00287738`、`max_current=1.75 A`、`vin=7.4 V`、`delay_substeps=4` 来自 manifest 的 actuator 块。

## 5. 范围限定（GPT R2 追加）

- 225 点力矩网格与 45/180 点角度/速度拆分，比较的是**同一静态函数**在两组输入下的输出，不是两条关节轨迹；动态闭环轨迹未验证。
- 结论只在所测工况与所测函数成立；不构成"执行器模型全域等价"或"真机性能"的声明。

## 6. 限制（未关闭）

- XL330 的子型号（M288-T）**仍缺一手 BOM/规格书**：现有一切证据只到 "xl330"。
- 力矩对账是**同一公式的两个实现**在 float64 下的逐位一致；它证明 kit 与 BAM 在给定参数下没有实现偏差，不证明 BAM 参数本身对应真机。
- 数值对账覆盖 10 个工况（静止、小误差、饱和、低速/反转、反电动势、低/高电压），不覆盖温漂与齿隙。
