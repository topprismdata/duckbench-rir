## 4. 可辨识性（GPT 复算为准）

- 双侧独立样本 t 检验、α=0.05、power=0.8、每组 n=5、sd=0.23436 → **MDE ≈ 0.4744 s**（我的正态近似 0.46 s 偏低）。
- 检测 0.2 s 效应：**每组约 23 run**（每组 20 run 时 power 仅 74.9 %）。
- sd 本身不确定：n=5 时 95 % CI 约 0.140–0.673 s（卡方），23 只是基于点估计的规划值。
- 预算结构裁决（GPT）：**优先增加独立 run 数，保持 5 min**；延长单次训练暂缓。
