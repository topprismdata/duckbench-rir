## 3. 概念框架（从实验里长出来的，不是先验）

1. **知识包 = 权重 + normalizer + host/命令语义**。E3 只隔离了权重（normalizer 相同），E4 变换了知识包整体（host/命令/归一化一起变），XCT 冻结知识包换任务。
2. **迁移有三个轴**：来源任务相似度（E4/F018）、目标命令条件（E2.1/XCT 低速）、以及执行接口的状态兼容性（E2 切换失稳）。
3. **命令是 Actor 输入**（`[48:55]`）；当前 Actor 无显式循环记忆。当前时序随机化协议未识别出额外收益（F014/F015）——这是该协议下的观察，**不建立**"无记忆导致无收益"的因果结论，也不等于前馈策略不能学习时序规律。
4. **组合效果同时受三层影响**：策略自身能力、切换点状态兼容性、执行契约（节点切换/命令语义）。节点拆分改变闭环行为（F008），跨步态拼接在边界退化（F009）——不能简化为"与策略好坏无关"。
5. **计分指标有盲区**：30 s 惩罚把"站着"和"持续跌倒"压成同一数字（F005/F016），必须并列位移、跌倒、切换后行为。

## 4. 方法与执行缺陷复盘

| 缺陷 | 发现方式 | 处置 |
|---|---|---|
| 初始化 dump 在 reset 前（E3） | GPT 复核 SD 与理论不符 | 改为 reset 后 dump；写入启动门禁 |
| 跌倒 episode/事件混用 | GPT 复算 | 双口径 + 冲线前/后 |
| staged 评价只绑单节点 | 全部 0/32 触发复盘 | 修正绑定，重跑评价 |
| recipe 哈希差异 | GPT 逐字段核对 | 追到一行注释；补配置与补丁 |
| C3 逐 tick 判断 ≠ 单次锁存 | GPT 读码 | 判 PROTOCOL FAIL，假设 NOT TESTED |
| 预算口径不一致 | GPT 汇总 | 登记 ESTIMATED OVERRUN（T2′ 77.9/75 min） |
| 报告数字与表格不一致 | GPT 逐格核对 | 追加 ERRATA，不改历史报告 |
| 预注册主指标被换成 best-half | GPT 复核协议 | 恢复全种子均值主指标；主指标 INCONCLUSIVE |
| 失败调用（程序名 0.1 vs 0p10）未登记 | 自检 | 记录 10 次失败 + 20 次重跑，纳入预算说明 |

## 5. 可复用结论（可直接引用）

- 在 DuckBench 冻结 Plant 内，两类因素都影响任务结果：预训练权重决定任务能否完成（E3），命令分布影响低速/调度条件下的稳定性（E2.1/T2′/XCT）；本阶段证据不支持给两者排序为"主导/次级"。
- 在所测条件下，命令分布训练带来低速命令适应收益（ΔD 六配对全负），但**未排除**个别策略/条件下的负迁移；标准命令下的跨任务表现差异在噪声量级内且方向不一致。
- 任何"组合/调度"结论都必须报告切换点的稳定性与切换后的行为，不能只看最终分数。

## 6. 不可外推边界

- 全部结论限于 Sprint v6、Ducky Steps v4、Hurdles v4 与冻结 Plant；不外推到实机、其他预算或其他策略架构。
- n=3 训练重复的结论只作筛选；32 个评价种子不是 32 次训练重复。
- F019 为**辅助候选发现**：未经过独立预注册检验（预注册主指标不针对 C2），4/4 组均值占优只作观察。
