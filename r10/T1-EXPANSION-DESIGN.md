## 1. 要解决的问题

E2.1/T2′ 已两次观察到"命令分布训练改善低速命令表现"（n=3，三 seed 同向）。扩样只提高精度，不改变方向；目标是让该发现的置信区间可报告。

## 2. 效应量与样本量（GPT 复算口径）

预注册主指标是**全种子平均惩罚时间**，不是 best-half。R7 的 V2 last 原始数据按训练种子配对：

| seed | C0 mean | C1 mean | 配对差 |
|---|---|---|---|
| 301 | 8.520 | 9.006 | +0.486 |
| 302 | 10.835 | 9.199 | −1.635 |
| 303 | 13.162 | 8.570 | −4.592 |

均值 **−1.914 s**，SD **2.551 s**（best-half 口径的 −1.294/0.731 不适用于本主指标）。

非中心 t、α=0.05：n=6 时检出 1 s 的功效约 **12.4 %**，检出 0.5 s 约 6.8 %；80 % 功效需约 54 对。

→ 60 min 方案**重新定位为"有限预算独立复现"**，不宣称 80 % 功效；预期 CI 很宽，跨 0 时如实关闭，不自动扩样。

## 3. 设计

| 项 | 值 |
|---|---|
| 臂 | T0（固定 0.19）、T1（episode 级二值抽样 0.10/0.19） |
| 种子 | 401–406（新，避免与 101–106、201–203、301–303 重叠） |
| 预算 | 2 臂 × 6 run × 5 min = **60 min**（有限预算复现，非确证性） |
| 顺序 | 每 seed 交替（奇 T0→T1，偶 T1→T0），跨 seed 轮换 T1 的时段 |
| 评价 | 固定 0.19 / 固定 0.10 / staged（height 0.15），best + last；seeds 8–39 |
| 主指标 | V2（固定 0.10）last 的全种子均值，C1−T0 配对 |
| 辅助 | best-half、完赛率、跌倒（互斥四分）、环境步数、命令暴露 |

## 4. 判定

- 若 95% CI 完全 < 0 且 |mean| ≥ 0.5 s → 登记为可复现的正向发现（仍限 DuckBench）。
- 若 CI 跨 0 → 报告"扩样后方向不稳"，不追加。
- 不因结果调整预算或臂。

## 5. 门禁

- 启动前：命令进入观测的探针（同 R7）；C1 暴露比例记录；配置仅 COMMAND 行不同。
- 零登录、零提交、fresh seeds 封存。
