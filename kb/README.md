## 方法纪律

1. 先诊断（时间/转速损失分解、奖励与计分同向性、归一化与探索状态），再决定训练。
2. 一次只改一个配方维度；多变量搜索可以并行找解，但不能归因。
3. 每个结论必须写"证据"与"失效条件"；失败也入库。
