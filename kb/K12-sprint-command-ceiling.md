# K12 Sprint 命令不是速度瓶颈

**证据**：raw `base-run-forward@2` warm start，训练命令 vx 0.7（40 min）→ 8–71 2.99；vx 0.9（30 min，seed 782）→ 2.98，64/64；中途曲线 4.26→2.98，末段仍在缓慢下降。

**结论**：把训练命令提高到 0.9 不改变天花板（≈3.0 s / 1.5 m/s）。冠军 2.17 s（2.07 m/s）需要不同训练栈或结构性改变，不是命令/预算微调。

**失效条件**：换训练栈（duck-arena-cli）或三节点 handoff 训练打通后重测。
