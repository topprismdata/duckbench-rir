# K21 Handoff 训练的 finish 策略无组合增益

**做法**：程序 `prep`(t<1.8s) → `run`；ENV `start="handoff"` + BANK（记录 run 节点的进入状态），warm start 自 Sprint 2.41 策略，10-min 训练 finish 专用策略（r21_fin18）。

**结果**：finish 专用策略单独整段 4.03 s；与 drive（2.41 策略）组合后 8–39/8–71 都是 **2.41 s**——与单节点 drive 完全相同。

**结论**：即使后续节点在"真实前序策略的进入状态分布"上训练，组合仍无增益；当前 Sprint 的瓶颈是单个策略的速度能力，不是节点组织。

**失效条件**：换更强 base 策略后再组合（组合可能只在每段都更强时才有意义）。
