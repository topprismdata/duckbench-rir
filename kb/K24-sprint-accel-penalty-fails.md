# K24 Sprint 加速不足惩罚无效

**实验**：H-S1，warm start 2.40 策略，加一项早期（t<1.5 s）速度不足惩罚 r=-2·max(0, v_ref(t)-vx)²，v_ref 以 1.4 m/s² 爬到 2.1；10 min，seed 911。

**结果**：in-loop best 2.42（起点 2.40，首 checkpoint 2.42 后无改善）；8–71 2.42、62/64（比基线差）。

**结论**：在已有 2.40 策略上，早期速度不足惩罚不能提高加速——策略的加速能力受优化器/网络容量限制，非奖励信号缺失。

**失效条件**：换网络容量、优化器或更长预算后重测。

**图谱**：H-S1 → 证伪；Sprint 剩余差距的假设需转向"容量/训练栈"（H-S3）。
