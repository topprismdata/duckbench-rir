# K06 节点拆分与切换

**证据**：
- Sprint 3 节点同权重（raw 0.7）= 3.28，与单节点一致 → 拆分中性；
- 混合不同训练程度权重 = 3.16–3.33（无增益）；
- handoff 专门化的 finish 策略组合后 11.27 s（切换失稳）；
- Steps 两节点同策略 25–28/32 随阈值波动（拆分改变完赛集合）。

**结论**：节点拆分本身不产生收益；收益需要"每阶段权重都适应前序策略产生的进入状态分布"——当前工具链不支持该训练方式。

**操作性**：单节点未触顶前，不投入多节点工程。

**失效条件**：有 handoff-bank 训练支持并验证组合增益。
