# K02 库内强策略短微调常退化

**观察**（8–71，本地）：
- Wheel：库内 5.33 → 5-min 5.29 → 20-min 续训中途 5.54（退化）；
- Saucer：库内 55.4 → 5-min 53.6（best）/51.8（last），训练曲线首个 checkpoint 即低于起点；
- Hurdles：库内 2.84 → 5-min 2.835（无增益）。

**假设**：这些库内 move 的父策略已训练 30M+ 步，在任务奖励下接近局部最优；kit 的 PPO 默认配置（LR 1e-4–2e-4、探索 std 大）在短预算内主要引入噪声。

**对照**：Steps 的成功来自"我们自己的 5-min 策略"（弱于库内、仍有空间）长续训，而不是库内强策略。

**操作性**：对强库内策略，优先 (a) 降低 LR/探索并跑 ≥20 min，或 (b) 从更弱/更任务匹配的起点出发。

**失效条件**：换奖励或换任务后，库内策略不再接近最优。
