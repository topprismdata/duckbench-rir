# 研究结论边界（CLAIM-BOUNDARIES）

用途：防止后续研究、宣传或二次开发把局部结果过度推广。左列是被证据支持的表述，右列是不被支持的表述。

| 可以说 | 不能说 |
|---|---|
| 在冻结 DuckBench Plant、Sprint v6、5 min 预算下，预训练 Actor 权重条件 192/192 完赛、随机重置 0/192（含最终检查点） | 任何预训练策略都优于随机初始化 |
| 在 Ducky Steps v4、当前策略与评价种子下，侧向运动先验相对同配置随机权重有部分迁移收益（10.7/32 vs 0/32） | 侧向技能可以直接组合到前向任务 |
| 同一策略拆成两个节点会改变可重复的闭环行为（同策略 25–28/32 随阈值波动） | 所有节点拆分都有害（或都无害） |
| 在所测策略、切换条件及评价种子下，跨步态组合出现明显任务性能退化，且随切换高度阈值升高而变差 | 不同步态永远无法组合 |
| 命令分布随机化训练在低速命令下改善任务表现（7.75→6.71 s，三个训练种子同向） | 已经获得通用的命令鲁棒性 |
| 5 min 预算、单一高度触发机制下，阶段命令训练未显示额外收益 | 阶段命令学习没有研究价值 |
| 命令值分布适应与时序调度能力是两个不同问题（T1 每 episode 抽一次命令） | T1 已经学会 episode 内动态调度 |
| EMA 是已识别的平台差异；在 Python 诊断环境中改变闭环结果，方向随命令非单调 | EMA 是竞赛漏洞 / EMA 提高成绩 |
| BAM 两版本在测试工况下力矩/摩擦律一致、供电模型换算后等价 | 两版本全域动力学等价 |
| 30 s 惩罚会把"站着不动"和"持续跌倒"压成同一个数字 | 奖励函数本身有缺陷（未证） |

## 证据等级

- **强**：E3（6 对配对，CI 远离 0）、E1 方差估计、FINDING-005/007/008（确定性）。
- **探索性**：FINDING-006（n=3，CI 跨 0）、FINDING-010（n=3 训练重复）。
- **行为层**：FINDING-009（无内部状态观测）。
- **负结果**：FINDING-011（限定 5 min 与单触发机制）。
- **候选/未验证**：FINDING-012。

## 计数口径

- "32 个评价种子"是每个训练结果的评价集，不是 32 次独立训练重复。
- FINDING-010 的"三个训练种子同向"是 n=3 的训练重复证据。
- 跨实验比较必须并列 wall-clock、环境步数、更新次数与命令分布（见 `r6/SYNTHESIS.md` §3）。
