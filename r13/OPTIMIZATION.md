# R13 — Sprint 成绩优化（工程路线，用户目标）

目标：把 Sprint 提交从 3.27 s 推向榜首量级（记录 2.17 s）。这是工程/预算问题，不再回答研究问题。

## 1. 已知事实

| 项 | 值 |
|---|---|
| 我们的最好提交 | A1-S107：3.27 s（5.2 min 训练，单节点 raw vx 0.7） |
| 榜首 | 2.17 s（27 min 训练，3 节点：launch 0.3 s → drive（t≥1.8 s）→ finish，head 0.72/0.72/0.8） |
| #2 | 2.22 s（4 h27 min，带 `trunk_speed` exploit 标记） |
| #3 | 2.30 s（41 min，4 节点） |

Sprint 需要 4.5 m；3.27 s ≈ 1.38 m/s，2.17 s ≈ 2.07 m/s → 需要约 +50 % 平均速度。

## 2. 零训练探测（已完成）

|---|---|---|
| raw 命令 vx 0.55 / 0.70 / 0.90 / 1.10 | 3.67 / **3.28** / 30.0 / 30.0 | 0.70 是训练点，越界直接失效 |

| 3 节点同权重（raw 命令 0.7） | **3.28 s（32/32）** | 节点拆分本身中性，收益必须来自不同权重 |

## 3. 路线（按性价比排序）

1. **延长单节点训练**：同一 warm start（`base-run-forward@2`，raw 0.7），20–40 min。预期 2.6–3.0 s。
2. **多种子挑选**：同一预算下 2–3 个种子，取本地 best-half 最好者（榜单导向，允许）。
3. **阶段专门化**：把足够好的策略分别短训成 launch（0–0.3 s）与 finish（末段）权重，按 #1 的 3 节点结构组合；先用同权重 3 节点验证结构中性（已完成）。
4. **命令微调**：最终策略在 0.65–0.75 区间做 0.05 步长扫描（零训练）。

## 4. 预算与纪律

- 用户已授权"优化拿成绩"，故不再走研究级门禁；但每次提交前仍需本地 8–39 + 40–71 双评价，避免用一次幸运种子。
- 每日提交额度 19 次；不刷榜，只交"本地双评价都更好"的版本。
- 记录每个 run 的训练时长、TS 结果、提交 attempt。

## 6. 与榜首的差距

- 我们 3.06 s（5→20 min 单节点）；#1 2.17 s（27 min、3 节点、head 0.72）；#2 2.22 s（4h27）；#3 2.30 s（41 min、4 节点）。
- 3.06→2.2 需要 +39 % 平均速度；单节点 20 min 已平台化（最后 1/3 仅 +0.03 s），仅靠延长同一配置收益有限。
- 下一杠杆（时间允许时）：多节点**不同权重**（launch/finish 分别短训），或 40 min 以上预算 + 多种子挑选。

## 7. 阶段专门化尝试（全部失败，已记录）

- launch 策略：以 O2 权重 `--init`、ENV `end_s=0.5` 训练 5 min（seed 621）→ 导出的整段 Sprint 仍为 3.00 s（起点即最好，训练无增益）。
- 组合：launch=该策略（0.3 s）、drive/finish=O2 → 8–39 **2.99 s**、40–71 **3.01 s**，未同时优于 O2（3.00/2.99）→ 不提交。
- head-0.72 walk-host（HFW warm start，20 min）：3.35 s（优于 5-min 的 3.77，但仍差于 raw 3.00）→ 不提交。
- handoff 1.5 s 起训的 finish 专用策略（8 min）：单独整段 4.45 s；与 O2 组合 **11.27 s（18/32）**——切换状态不兼容（同 R5.1 现象）。
- 1-min 克隆微调的 finish 策略与 O2 组合：3.01/3.00 s，无增益。

## 8. 上传副作用与处置

登录后，**每个 simulate/训练 run 都会在后台启动 `duckbench runs sync`**，把本地未上传的 practice replay 逐个推到站点（777 个 run，每个 9–10 个文件）。已在 43 个时手动停止一次；该进程会在下一次 CLI 调用时再次启动。

处置：本地评价一律加 `DUCKBENCH_NO_UPLOAD=1`（dist 支持的开关：`uploads are off … nothing leaves this computer`）；只有明确要提交的 attempt 才不加。已上传的 43 个 practice run 无法撤回，登记在案。

## 9. 结论

单节点 raw `base-run-forward@2` 在 20→40 min 上 asymptote ≈ **3.0 s**；所有阶段专门化/组合尝试均未超过它（长分歧的专门化策略在切换点失稳，短分歧克隆无增益）。当前最好成绩：**2.99 s，rank 4/9**（榜 #1 2.17 / #2 2.22 / #3 2.30）。若继续，需要按 #1 的方式做"同源克隆逐步分化 + 长时间训练"（27 min+），或接受 3.0 的天花板。
